# 청년 남녀는 점점 다른 곳에 산다 (1998–2025)

> ### **[▶ 지도 열기 — wherewindstay.github.io/gendered-space](https://wherewindstay.github.io/gendered-space/)**
>
> *연도 슬라이더를 움직이고 시군구를 누르려면 링크로 들어가야 합니다. GitHub 는 README 안에서 인터랙티브 콘텐츠를 실행하지 않습니다.*

전국을 저울에 올려 균형점을 찾으면 그것이 **인구중심점**입니다. 시군구마다 중심 좌표를 두고 그곳에 사는 인구만큼 무게를 주어 평균을 내면, 그 집단 전체를 대표하는 점 하나가 나옵니다. 집단을 성별·연령으로 나눠 각각의 점을 구하면 누가 더 멀리, 어느 방향으로 움직였는지 견줄 수 있습니다.

1998–2025년 사이 **청년 여성의 인구중심점은 22.9km**, **청년 남성은 18.1km** 이동했습니다. 전체 인구는 **13.1km** 였습니다. 방향은 모두 북서쪽, 수도권 쪽입니다. 청년 남성과 여성의 두 점 사이 거리는 **2.2km에서 6.7km로** 벌어졌고, 같은 기간 전 연령의 남녀 거리는 1km 안에 머물렀습니다.

박소현, [「심화되는 성별 갈등, 공간에서도 나타난다」](https://www.pressian.com/pages/articles/2024110722251788361)(프레시안 2024-11)의 정지 그림 세 장을 조작 가능한 지도로 다시 만들고, 2024·2025년 자료를 더한 것입니다.

## 화면 구성

| 화면 | 내용 |
|---|---|
| 왼쪽 지도 | 전체·청년 남성·청년 여성 세 인구중심점의 1998년부터 선택 연도까지의 궤적, 그리고 청년 남녀 사이 거리의 연도별 추이 |
| 오른쪽 지도 | 수도권(서울·인천·경기) 시군구별 청년 성비와 색 범례. 추이 그래프는 처음에 수도권 전체를 보여주고, 시군구를 누르면 그곳으로 바뀝니다(같은 곳을 다시 누르면 전체로 돌아옵니다) |
| 슬라이더 | 두 지도와 두 그래프가 함께 움직입니다. ▶ 를 누르면 연도가 자동으로 흘러갑니다 |

범례와 그래프는 각 지도 위에 얹혀 있고, 지도 아래에는 연도 슬라이더만 있습니다.

청년은 청년기본법 기준 만 19–34세, 성비는 여성 100명당 남성 수입니다.

| 무엇 | 출처 |

| 시군구 경계 | 통계청 SGIS 행정구역 경계 2021년 4분기 |

1998–2023년 인구중심점은 저자의 `centroid_sgg.R` 산출값을 그대로 썼습니다. 2024·2025년은 같은 방법(시군구 중심점을 인구로 가중평균, 2021년 4분기 경계)으로 계산했습니다. 같은 코드로 2023년을 다시 계산하면 원래 값과 0m 차이로 일치하므로, 두 구간을 이어 붙여도 시계열이 어긋나지 않습니다.

## 이 지도가 말해주지 않는 것

- **경계는 2021년 판으로 고정했습니다.** 전 기간을 하나의 지리에 맞춰 재기 위해서입니다. 그 이후 개편 — 2026년 인천의 신설 자치구 등 — 은 반영되지 않았습니다.
- **절대 위치에는 사는 곳이 아니라 등록한 곳이 섞입니다.** 군 복무와 대학 진학은 둘 다 청년의 등록지를 옮깁니다. 궤적은 각 집단이 **얼마나 멀리 갔는가**를 비교하기 위한 것이지 위치를 짚기 위한 것이 아닙니다.
- **안산·용인은 인구가 시 단위인데 경계는 구 단위입니다.** 시 값을 각 구에 그대로 표시했으므로 두 시 안의 구별 차이는 나타나지 않습니다.
- **통합시는 한 번만 셉니다.** 원자료에 시와 구가 함께 있으면 시 행을 버리는데, **그 해에 구 행이 실제로 있을 때만** 그렇게 합니다. 부천시는 2016년에 일반구를 폐지했다가 2024년에 되살려서, 이름으로 일괄 처리하면 그 사이 8년이 통째로 비어버립니다.
- **폐지·개편된 옛 시군구 코드는 현행 경계로 이어 붙였습니다**(인천 남구→미추홀구, 부천 3구, 군→시 승격 5곳). 슬라이더를 과거로 돌릴 때 구멍이 생기지 않게 하기 위해서입니다. 영통구(2003 분구)와 일산서구(2005 분구)는 그전에 존재하지 않았으므로 늦게 시작합니다.
- **오른쪽 지도의 초기 화면에서는 옹진군을 범위에서 뺐습니다.** 옹진의 도서는 동경 124.7도까지 뻗어 있어 함께 넣으면 서울·경기가 구석으로 밀립니다. 경계는 그려 두었으니 한 단계 축소하면 보입니다.
- **인구중심점은 요약이지 장소가 아닙니다.** 전혀 다른 두 분포가 같은 중심점을 가질 수 있습니다. 이 점이 답하는 것은 "이 집단이 어느 쪽으로 움직였는가"까지입니다.

## 성비를 읽을 때

1998년 양 끝은 옹진군 140.2와 일산구 85.1이었고, 2025년에는 옹진군 241.4와 마포구 80.8입니다. 서울과 인접 지역은 여초 쪽으로, 접경 군(옹진·연천·포천·가평)과 제조업 지역(이천)은 남초 쪽으로 기울었습니다. 옹진군 수치는 상주인구가 적은 데다 군 복무·어업 종사가 얹힌 결과이므로 인원이 아니라 비율로 읽어야 합니다.

## 기술 메모

- 단일 HTML 파일입니다. Leaflet 을 CDN 이 아니라 파일 안에 넣어 두어서 디스크에서 바로 열어도 동작합니다. 네트워크가 필요한 것은 배경지도 타일뿐입니다.
- 빌드 도구도 프레임워크도 쓰지 않았습니다. 그래프는 SVG 를 직접 그립니다.
- 화면의 문구는 데이터에서 생성되므로, 연도가 추가돼도 도입부 수치가 어긋나지 않습니다.
